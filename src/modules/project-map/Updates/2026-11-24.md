# Project Map Updates — November 24, 2026

## New: Save the Missive email with each project

Many projects come to us by email through Missive. You can now save the link to that email right on the project, so anyone can open it again later without searching their inbox.

### How to save the link
1. In Missive, open the email for the project and copy its link.
2. In Project Map, click **Add Project** (or open a project and choose **Edit**).
3. In the **Customer Information** section, paste the link into **Missive Email Link** (just below Linked Dealer).
4. Click **Create Project** or **Save Changes**.

Good to know:
- The field is optional. Projects without a link work exactly as before.
- The link must start with `http://` or `https://`. If it doesn't, you'll see a message asking you to fix it.
- Once a link is pasted, an **Open in Missive** link appears beside the box so you can check it's the right email.

## New: Open the Missive email with one click

Projects that have a saved Missive link now show a small **envelope icon** next to the project name. Click it and the email opens in a new browser tab. Your Project Map page stays where it was.

You'll see the envelope in these places:
- **Projects list** — next to each project's name.
- **Project details panel** — next to the project name at the top.
- **Runs** — next to each stop's name in the run panel.
- **Run Master** — next to each project's name in the run's project table.
- **Run Calendar** — next to each stop's name when you open a run.

Good to know:
- No envelope means no Missive link has been saved for that project yet. Add one with **Edit**.
- Clicking the envelope only opens the email. It won't select, open or move the project or stop.
- The envelope doesn't show on map pins, the reminders bell, the Paid Sheet, the Repair Form, or printouts. To open the email from the map, click the pin to open the project details panel and use the envelope there.
