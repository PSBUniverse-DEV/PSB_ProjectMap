# Project Map Updates — November 28, 2026

## New on the Analytics page: speed, runs and repairs

The Analytics page has five new charts:
- **Time spent in each status**: how many days projects usually stay in each status before moving on.
- **Order to install**: how many days it takes from an order to the project being installed, per week or month.
- **Runs per week or month**: how many runs there were, coloured by run status.
- **Runs that kept their first date**: how many runs kept the date they were first given, and how many were moved.
- **Repairs per week or month**: how many repairs were opened and how many were finished.

Good to know:
- They all follow the Period, State and Building category filters (the run charts count all runs).
- The status, install and repair charts use status history, so they only go back to the day it started and fill up over time.
- Click **Table** on any chart to see its numbers as a list.
