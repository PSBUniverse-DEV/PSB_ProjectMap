# Project Map Updates — November 29, 2026

## Fixed: more accurate Analytics numbers

- **Time spent in each status** now only counts stays that started after status history began. Before, stays that had started earlier were counted from that day, so the averages looked shorter than they really were. The chart may show fewer moves for a while; the numbers it shows are now correct.
- **Runs** (the number at the top) and **Runs that kept their first date** no longer count cancelled runs. Cancelled runs still show in **Runs per week / month**.

## New on the Analytics page: more on projects

Under **More on projects** there are six new charts:
- **Open value by status**: the total value of open projects in each status, right now.
- **Building categories**: orders in the period by building category, highest value first.
- **Average order value**: the average and middle order value per week or month.
- **Orders by state**: which states the orders came from.
- **Projects not updated**: open projects nobody has updated for a while, using the same number of days as the reminders bell. Click **Table** to see the list of projects.
- **Customer care progress**: how many open projects are at each welcome call, confirmation and permit step, and how many have none set.

They follow the Period, State and Building category filters, like the rest of the page.

## New on the Analytics page: more on runs

Under **More on runs** there are six new charts (cancelled runs are left out):
- **Average stops per run**: how many stops a run usually has, per week or month.
- **Run value**: the total planned value of the runs.
- **Planned miles** and **Planned drive hours**: from each run's route estimate. Runs whose route has no miles yet are not counted in miles.
- **Team workload**: how many runs, stops, miles and hours each team had.
- **Install days**: a calendar-style grid of which weekdays installs are booked on. Darker squares mean more installs that day; point at a square to see the number, or click **Table** for every week.

## New on the Analytics page: click to see the projects

On the Analytics page you can now see exactly which projects make up a number:
1. Click a bar in a project chart (for example **Projects by status** or **Top dealers**), a day in **Install days**, or a row in a chart's **Table**.
2. A list opens with those projects: status, state, dealer, value and a date.
3. Click **Open on map ↗** next to a project. The Project Map opens in a new tab with that project selected and its details showing. Your Analytics page stays as it was.

In **Projects not updated**, clicking a row in the Table opens that project on the map straight away.
You can also use the keyboard: Tab to a table row or an Install days square and press Enter.

## New on the Analytics page: click to see the runs

The run charts can now be clicked too:
- Click a bar in **Runs per week / month**, **Runs that kept their first date**, **Run value**, **Planned miles**, **Planned drive hours** or **Team workload**, or a row in their **Table**.
- A list opens with those runs: run code and name, date, status, stops, planned value, miles, hours and team.
- In the run charts with colours (status, kept / rescheduled), clicking one colour lists only those runs; clicking a row in the Table lists all runs of that week or month.

## Fixed: "All other" lists on the Analytics page

Clicking **All other teams** (or **All other states**) now lists only the teams or states folded into that bar. Before, it also listed the runs with no team (or projects with no state), which have their own bar.

## Faster Analytics page

The Analytics page now opens faster and will stay fast as more projects are added.
- When you change the Period, State or Building category, the charts fade for a moment and the top of the page says **Updating…** while the new numbers load. Going back to a filter you already used is instant.
- When you click a bar to see the projects or runs behind it, the list says **Loading…** for a moment, then fills in.
- The numbers and charts are the same as before.

## Analytics page: smoother and easier to use

- **Numbers as of …**: the top of the page shows the time the numbers were loaded. Click **↻ Refresh** to load the latest numbers.
- **Quicker filters**: changing the Period, State or Building category right after another change is quicker now.
- **A placeholder while loading**: grey boxes show while the page gets its numbers ready, instead of a blank screen.
- **Search in long lists**: when a list from a bar has more than 10 projects or runs, type in the search box to narrow it, for example a dealer or a client name. The count shows how many match, for example "12 of 503 projects".
- If the numbers cannot be updated (for example the connection drops), the filters go back to what the charts show, so everything on the page stays in step.
