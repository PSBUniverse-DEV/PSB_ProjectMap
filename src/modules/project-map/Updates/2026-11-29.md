# Project Map Updates — November 29, 2026

## Fixed: more accurate Analytics numbers

- **Time spent in each status** now only counts stays that started after status history began. Before, stays that had started earlier were counted from that day, so the averages looked shorter than they really were. The chart may show fewer moves for a while; the numbers it shows are now correct.
- **Runs** (the number at the top) and **Runs that kept their first date** no longer count cancelled runs. Cancelled runs still show in **Runs per week / month**.

## New on the Analytics page: more on projects

Under **More on projects** there are six new charts:
- **Open value by status**: the total value of open projects in each status, right now.
- **Building categories**: orders in the period by building category, highest value first.
- **Average order value**: the average and middle order value per week or month.
- **Orders by state**: which states the orders came from.
- **Projects not updated**: open projects nobody has updated for a while, using the same number of days as the reminders bell. Click **Table** to see the list of projects.
- **Customer care progress**: how many open projects are at each welcome call, confirmation and permit step, and how many have none set.

They follow the Period, State and Building category filters, like the rest of the page.
