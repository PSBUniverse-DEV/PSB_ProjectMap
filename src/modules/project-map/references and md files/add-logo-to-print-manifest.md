STEP 1 — Make the logo servable as a plain URL
─────────────────────────────────────
The print manifest is generated by writing raw HTML into a separate
browser window (`printWindow.document.write(...)`). That window is NOT
part of the React/Next.js component tree, so it can't resolve a webpack
`import` reference the way normal JSX can — it needs a plain, absolute
URL string it can put directly into an `<img src="...">` tag.

Check whether `public/` at the project root already serves static assets
(most Next.js apps do — anything in `public/` is servable at the root
URL, e.g. `public/images/logo.png` → `/images/logo.png`).

- If a `public/` folder exists: copy (do not move, in case other code
  still imports the original) `src/styles/psb_logo_notitle.png` to
  `public/images/psb-logo.png`.
- If there is a project convention for where static/public assets live
  that differs from this, follow that existing convention instead — the
  goal is just: the logo must be reachable via a plain URL path like
  `/images/psb-logo.png` that works when hardcoded into an HTML string.

Do NOT attempt to reference the logo via a relative `import` path inside
the print HTML template string — it will not resolve correctly since
that HTML is written to a separate window, not rendered by React.
